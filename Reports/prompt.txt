第三步（Session 3）：生成 OCR 文本解析器（必须防止 AI 幻觉脑补）


你是一名专注自然语言处理与信息抽取的算法工程师。
在名片全能王项目中，系统需要从 OCR 识别出的乱序文本（Raw Text）中抽取出 8 个标准联系人字段。
作业特别强调：
1. 概率性功能验收：AI 不允许“补全”名片上不存在的信息。如果原文没有网址，严禁推测出网址，必须返回 nil。
2. 必须具备人名与公司混淆（如 Jordan Lee vs Lee Consulting）、多电话号码（区分 Mobile、Office、Fax）的识别能力。

请为我实现一个纯本地的规则/正则增强版联系人解析器（BusinessCardFieldParser.swift）：
1. 结构体定义：
   struct ParsedCardResult {
       var name: String?
       var company: String?
       var jobTitle: String?
       var mobile: String?
       var phone: String?
       var email: String?
       var website: String?
       var address: String?
       var rawText: String
   }
2. 实现核心解析方法：
   static func parse(rawText: String) -> ParsedCardResult
3. 解析逻辑要求：
   - 使用严谨的正则匹配 Email、Website、常见手机与座机号（包含区分 Tel/Mobile/Fax 前缀标签）。
   - 过滤掉无关噪声符号，提取公司（包含常见后缀：Co., Ltd., Inc., 科技, 大学, 咨询 等）与职位（Manager, Director, 教授, 工程师 等）。
   - 严格守则：无法 100% 确认的字段返回 nil，宁缺毋滥，不得填充虚假数据。
4. 为这个 Parser 编写一套基于 XCTest 的单元测试（BusinessCardFieldParserTests.swift）：
   - 至少覆盖 5 组边界用例：包含中英双语、缺少 Website（验证是否为 nil）、包含 Fax 与 Mobile、名片中包含公司名类似人名的情况。
